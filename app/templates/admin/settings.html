{# Note de configuration #}
Configuration

Pour modifier la configuration de la plateforme, éditez le fichier .env à la racine du projet, puis redémarrez Flask.

Paiement

Pour activer les paiements, configurez :

  • PAYMENT_PROVIDER (ex: generic)
  • PAYMENT_API_URL
  • PAYMENT_API_KEY
  • PAYMENT_WEBHOOK_SECRET
WhatsApp Cloud API

Pour envoyer de vrais messages :

  • Mettre WHATSAPP_DEV_MODE=0
  • Configurer WHATSAPP_ACCESS_TOKEN
  • Configurer WHATSAPP_PHONE_NUMBER_ID
  • Configurer WHATSAPP_BUSINESS_ACCOUNT_ID
Après modification du fichier .env, un redémarrage de Flask est nécessaire pour que les changements soient pris en compte.
